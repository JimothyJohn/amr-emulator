Five minutes to a moving robot

$ uv run vda5050-emulator
vda5050-emulator: VDA 5050 3.0.0, embedded broker on mqtt://0.0.0.0:1883
robot: vda5050/v3/amr-emulator/vagv-0001/{order,instantActions,state,connection,...}

five-minute check with any MQTT client:
  subscribe: vda5050/v3/+/+/state
  publish an order to: vda5050/v3/amr-emulator/vagv-0001/order
  fault injection (JSON): vda5050/v3/amr-emulator/vagv-0001/_emulator
    e.g. {"emergencyStop": "MANUAL"} or {"battery": {"level": 7}}
$ vda5050-emulator --broker 10.0.0.5 --spec 2.1.0 --robots 5 --time-scale 60
# joins YOUR existing MQTT broker — no infrastructure changes;
# --spec switches the protocol generation (2.0.0 / 2.1.0 / 3.0.0);
# --robots N puts a small fleet on the same broker;
# --time-scale runs simulated time faster for soak tests.
$ docker compose up vda5050          # broker on :1883 + two robots
$ docker build -f Dockerfile.vda5050 -t vda5050-emulator .
$ docker run --rm -p 1883:1883 vda5050-emulator --robots 2

    SurfaceCoverage
    Protocol versions2.0.0, 2.1.0, 3.0.0 — switchable per robot (--spec); topic roots uagv/v2 and vda5050/v3
