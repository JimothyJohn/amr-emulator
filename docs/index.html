A MiR robot you can develop against.
No robot required.

Mobile Industrial Robots (MiR) AMRs — the autonomous carts that haul material around factories — are controlled entirely through a REST API. This site is a faithful emulator of that API, built from MiR's official documentation and running at one public URL. Write your integration against it in any language; when it works, swap this URL for your real robot's IP address and the same code drives the robot.

Documentation & primary sources: MiR robot REST API reference (one PDF per version, free support-portal account) · MiR Fleet Enterprise Integration API (public Swagger UI)

    Endpoints
    
  
    
    Everything hangs off one public base URL: https://amr-emulator.com. Put the MiR
    software version you want in the path — /3.8.1/api/v2.0.0/status is robot
    software 3.8.1, /latest/… is the newest — and call the same paths a real
    robot serves. On a real robot there's no version prefix, so switching over is just changing
    the base URL.
  
    
  
    
    
    PathWhat it serves
    
    
    /<version>/api/v2.0.0/…The emulated MiR robot REST API for that software version (also /latest/…).
    
    
    /fleet/<version>/api/v1/…The emulated MiR Fleet Enterprise Integration API (also /fleet/latest/…); auth is an x-api-key header, default key distributor. Each fleet embeds robot emulators it controls over their own REST API.
    
    
    /<version>/swagger.jsonMachine-readable spec, Swagger 2.0 (and /<version>/openapi.json for OpenAPI 3.0).
    
    
    /fleet/<version>/openapi.jsonThe official Fleet OpenAPI 3 document, served verbatim.
    
    
    /<version>/Per-version JSON index: operation count, auth, session header, spec provenance.
    
    
    /consoleThis page (also served at / to browsers) — catalog, telemetry, virtual robot sessions.
    
    
    /JSON index of everything above — browsers get this page instead.
    
    
    /healthzLiveness + the list of tracked versions.
